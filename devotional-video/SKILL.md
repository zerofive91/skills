# 묵상 영상 제작

묵상 영상의 목적은 정보 전달이 아니라 **시청자가 말씀 앞에 머물게 하는 것**이다.
그래서 일반 유튜브와 기준이 다르다. 빠른 컷과 효과 대신 **또렷한 목소리, 읽기 편한 자막, 숨 쉴 여백, 일관된 형식**이 전문가의 결과물을 만든다.

## 핵심 원칙

1. **말씀이 주인공이다.** 본문은 화면에 크게, 목소리로 천천히. 해설은 본문을 가리지 않는다.
2. **목소리가 음악보다 항상 분명하다.** 음악은 분위기를 깔 뿐, 단어 하나도 덮으면 안 된다.
3. **여백(침묵)은 편집 실수가 아니라 설계다.** 핵심 구절 뒤에는 의도적으로 2~4초 멈춘다.
4. **매회 같은 뼈대.** 순서·길이·화면 배치를 고정하면 시청자는 형식이 아니라 말씀에 집중하고, 제작자는 매번 고민하지 않아도 된다.
5. **첫 30초에 오늘의 이유를 준다.** 차분해도 느슨하면 안 된다. 인사와 로고보다 시청자의 마음을 짚는 한 문장이 먼저다.

## 작업 절차

사용자가 본문(또는 주제·원고)을 주면 아래 순서로 진행한다. 빠진 정보는 짧게 묻거나 합리적으로 가정하고 가정을 밝힌다.

1. **기본 정보 확인**: 본문 범위, 사용할 역본(개역개정, 새번역 등), 목표 길이, 시리즈 이름·회차, 진행자 얼굴 노출 여부
2. **한 문장 메시지 정하기**: "이 영상을 본 사람이 오늘 붙들 한 문장"을 먼저 쓴다. 모든 내용은 이 문장을 향한다.
3. **대본 작성**: 아래 "대본 구조" 형식으로, 구간별 시간과 화면 지시를 함께 쓴다.
4. **낭독 가이드 표시**: 대본에 멈춤(`/` 짧게, `//` 길게)과 강조어(**굵게**)를 표시한다.
5. **편집 지시서 작성**: 장면, 자막, 음악, 음량을 "편집 지시서 템플릿"으로 정리한다.
6. **패키징**: youtube-packaging 스킬로 제목·썸네일·설명란을 만든다.
7. **최종 점검**: "업로드 전 체크리스트"로 확인한다.

## 대본 구조

전통적인 렉시오 디비나(읽기 → 묵상 → 기도 → 머무름)를 영상 길이에 맞게 줄인 형식이다. 기본은 **5~8분**.

| 구간 | 시간(7분 기준) | 내용 | 화면 |
|---|---|---|---|
| ① 여는 문장 (훅) | 0:00–0:20 | 시청자의 마음·상황을 짚는 한두 문장. 인사는 여기 끝에 한 줄만 | 분위기 영상 + 자막 |
| ② 본문 낭독 | 0:20–1:30 | 본문 전체를 천천히 1회 낭독 | 본문 자막 크게, 배경 단순 |
| ③ 붙들 구절 | 1:30–2:00 | 오늘의 핵심 구절 하나를 다시 읽고 **3초 멈춤** | 그 구절만 화면 가운데 |
| ④ 묵상 (해설) | 2:00–5:00 | 배경·의미 1개 → 삶의 장면 1개 → 적용 1개. 요점은 최대 3개 | 진행자 또는 B-roll, 요점 키워드 자막 |
| ⑤ 질문 | 5:00–5:40 | 시청자가 스스로 답할 질문 1~2개, 질문 뒤 **5초 침묵** | 질문 자막만, 음악만 |
| ⑥ 기도 | 5:40–6:40 | 1인칭 복수("우리")로 짧게, 시청자가 따라 할 수 있게 | 차분한 영상, 자막 |
| ⑦ 맺음 | 6:40–7:00 | 핵심 구절 한 번 더 + 다음 회 예고 한 줄 + 구독은 한 문장만 | 시리즈 엔딩 화면 고정 |

### 대본 작성 규칙
- 문장은 짧게. 한 문장에 생각 하나. 낭독했을 때 숨이 차면 나눈다.
- 해설 문장은 "~합니다"체로 통일하고, 기도는 "~합니다/~하소서" 중 하나로 시리즈 내내 고정.
- 어려운 신학 용어는 쓰면 바로 한 줄로 풀어 준다.
- 예화는 하나만, 구체적으로 (장소·시간·감정이 보이게).
- 적용은 "오늘 하루 할 수 있는 한 가지"로 끝맺는다. 추상적 결단("더 사랑합시다") 대신 구체적 행동("오늘 연락이 끊긴 한 사람에게 안부를 묻습니다").
- 본문 해석은 문맥을 벗어나지 않게: 앞뒤 절, 책의 흐름, 원래 독자를 한 번 확인하고 쓴다. 확신이 없는 해석은 단정하지 않는다.
- 정죄·공포·물질적 약속(“믿으면 부자가 된다”)으로 끌지 않는다.

## 낭독 가이드

- **속도**: 일반 내레이션보다 느리게, 분당 약 250음절 안팎(성경 본문 낭독은 더 느리게). 1분 분량 원고 ≈ 공백 제외 230~260자.
- **멈춤 표시**: 쉼표 자리 `/` 0.5초, 문장 끝 `//` 1~1.5초, 핵심 구절 뒤 `///` 3초.
- **강조**: 한 문장에 강조어는 하나. 대본에 **굵게** 표시한다.
- **녹음 환경**: 이불·옷장 등 흡음되는 좁은 곳, 입과 마이크 거리 한 뼘(15~20cm), 마이크는 입 약간 옆으로(파열음 방지). 휴대폰으로 녹음해도 이 조건이면 충분하다.
- 첫 녹음 전 10초간 **방의 잡음만** 녹음해 두면 편집 툴의 노이즈 제거에 쓸 수 있다.
- 실수하면 문장 처음부터 다시 읽는다 (중간부터 이어 붙이면 억양이 끊긴다).

## 음악과 음량

### 음량 기준
| 항목 | 기준 |
|---|---|
| 최종 영상 전체 음량 | 약 **-14 LUFS** (유튜브는 이보다 큰 소리를 자동으로 낮춘다) |
| 최고 피크 | **-1 dBTP** 이하 (찢어지는 소리 방지) |
| 배경음악 vs 목소리 | 말하는 동안 음악은 목소리보다 **약 18~24dB 낮게** |
| 목소리 없는 구간 | 음악을 자연스럽게 올리되, 목소리 구간 대비 +6dB 안쪽 |
| 덕킹 | 목소리가 시작되면 음악이 3~6dB 더 내려가도록 (캡컷·프리미어의 '자동 덕킹' 사용) |

- 편집 툴에 LUFS 측정이 없으면: 목소리 피크가 -6dB 근처, 음악 피크가 -20dB 근처면 대체로 맞다.
- 마지막에 **휴대폰 스피커, 이어폰, 노트북** 세 곳에서 들어 본다. 휴대폰 스피커에서 단어가 또렷하면 통과.

### 음악 선택
- 가사 없는 곡만. 가사가 있으면 말씀·해설과 경쟁한다.
- 피아노, 패드, 앰비언트처럼 리듬이 약한 곡. 드럼·강한 박자는 피한다.
- 한 영상에 음악은 1곡(길면 2곡). 구간이 바뀔 때 2~3초 페이드로 넘긴다.
- **저작권**: 유튜브 오디오 보관함, 또는 유튜브 사용이 명시된 라이선스 음원만 쓴다. 찬양 원곡·편곡은 교회용 라이선스로는 유튜브 게시가 허용되지 않는 경우가 많으니 반드시 확인한다.

## 자막 규칙

넷플릭스 한국어 자막 기준을 묵상 영상에 맞게 적용한다.

- **한 줄 최대 16자 안팎, 최대 2줄.** (영문·숫자·공백·문장부호는 반 글자로 계산)
- **읽기 속도는 초당 12자 이하.** 넘치면 문장을 나누거나 줄인다 (본문 자막은 줄이지 말고 나눈다).
- 두 줄로 나눌 땐 **아래 줄이 더 길게**, 의미 단위(어절)로 끊는다. 조사 앞에서 끊지 않는다.
- 자막 끝에는 마침표·쉼표를 찍지 않는다. 말줄임은 `…` 한 글자.
- 글꼴은 굵은 고딕 계열(Pretendard, 나눔스퀘어, Noto Sans KR) **흰색 + 반투명 검은 그림자/박스**. 배경이 밝아도 읽혀야 한다.
- 위치는 화면 아래 중앙, 아래 여백 약 10%. 유튜브 컨트롤바·자동자막과 겹치지 않게.
- **본문 자막은 다른 스타일로 구분**: 화면 가운데, 더 큰 크기, 끝에 출처 `(시편 23:1, 개역개정)`를 작게.
- 자막 파일(.srt)을 따로 올리면 검색과 자동번역에 도움이 된다. 화면에 박은 자막과 별도로 올려도 된다.

## 화면 구성과 편집 리듬

- **안전 영역**: 중요한 글자는 화면 가장자리에서 5% 이상 안쪽에.
- **장면 길이**: 컷은 보통 4~8초. 일반 유튜브(2~3초)보다 길게, 그러나 같은 화면이 15초 넘게 멈춰 있지는 않게 (천천히 확대되는 효과, 다른 각도 B-roll로 변화).
- **전환**: 기본은 그냥 컷, 구간이 바뀔 때만 0.5~1초 디졸브(교차 페이드). 회전·번쩍임·슬라이드 같은 화려한 전환은 쓰지 않는다.
- **B-roll**: 빛, 새벽, 길, 물, 손, 창문, 책장 넘기기처럼 상징이 분명한 장면. 해설 내용과 연결되는 장면을 고른다. 무료 소스: Pexels, Pixabay, Unsplash(사진).
- **색**: 영상 전체에 같은 색감 필터(LUT) 하나를 고정. 따뜻하고 약간 낮은 채도가 묵상 톤에 맞다.
- **진행자 촬영**: 눈높이 카메라, 창문 빛을 얼굴 옆(45도)에서, 배경은 단순하게, 화면 1/3 지점에 눈.
- **고정 요소**: 오프닝 문구 위치, 본문 자막 스타일, 엔딩 화면(구독·다음 영상 카드)은 매회 같은 템플릿을 쓴다.

## 편집 지시서 템플릿

```
# [시리즈명] #[회차] — [본문]
한 문장 메시지:
역본:
총 길이 목표:

| 시간 | 구간 | 낭독/대사 (요약) | 화면 (영상·사진) | 자막 | 음악·음량 |
|---|---|---|---|---|---|
| 0:00 | 여는 문장 | "잠이 오지 않는 밤이 있지요." | 새벽 창문 B-roll, 천천히 확대 | 하단 기본 자막 | 음악 시작, 목소리보다 -20dB |
| 0:20 | 본문 낭독 | 시편 4:1-8 | 단색 배경 | 본문 자막(가운데, 큰 글씨) | 유지 |
| 1:30 | 붙들 구절 | 4:8 재낭독 + 3초 멈춤 | 구절만 가운데 | 구절 + 출처 | 멈춤 동안 +3dB |
| ... | | | | | |
```

## 업로드 전 체크리스트

**내용**
- [ ] 한 문장 메시지가 있고, 해설 요점은 3개 이하다
- [ ] 본문을 문맥 안에서 해석했고, 단정하기 어려운 해석은 단정하지 않았다
- [ ] 적용이 오늘 할 수 있는 구체적 행동 하나다
- [ ] 첫 20초 안에 인사·로고보다 여는 문장이 먼저 나온다

**소리**
- [ ] 전체 약 -14 LUFS, 피크 -1 dBTP 이하
- [ ] 음악이 어떤 단어도 덮지 않는다 (휴대폰 스피커로 확인)
- [ ] 음악은 가사 없는 곡이고 유튜브 사용 허락이 확인됐다
- [ ] 잡음·숨소리·입소리가 거슬리지 않는다

**자막과 화면**
- [ ] 자막은 한 줄 16자 안팎, 2줄 이하, 초당 12자 이하
- [ ] 본문 자막에 출처(장:절, 역본)가 있다
- [ ] 글자가 화면 가장자리 5% 안쪽, 하단 컨트롤바와 겹치지 않는다
- [ ] 오탈자 없음 (특히 성경 인명·지명, 장절 번호)
- [ ] 전환은 컷과 디졸브만, 색감은 영상 전체가 같다

**시리즈**
- [ ] 오프닝·본문 자막·엔딩이 시리즈 템플릿과 같다
- [ ] 제목·썸네일·설명란은 youtube-packaging 체크리스트를 통과했다

## 업로드 후

- 시청 지속 그래프에서 **크게 떨어지는 지점**을 찾아 기록한다. 대개 인사가 길거나, 해설이 본문과 멀어진 곳이다.
- 같은 시리즈의 다른 회차와 평균 시청 비율을 비교하고, 잘 된 회차의 여는 문장·길이·구성을 다음 회에 반복한다.

## 출력 형식

사용자에게는 다음 순서로 전달한다.

1. 한 문장 메시지
2. 대본 (구간·시간·멈춤·강조 표시 포함)
3. 편집 지시서 표
4. 사용할 음악 분위기와 음량 설정
5. 체크리스트 결과
6. (요청 시) youtube-packaging 결과

근거 자료는 [references/sources.md](references/sources.md)에 정리되어 있다.
