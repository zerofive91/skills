# 유튜브 패키징 (썸네일 · 제목 · 설명 · 훅)

시청자가 영상을 **클릭할지**는 썸네일과 제목이, **끝까지 볼지**는 첫 30초가 결정한다.
이 스킬은 영상 한 편을 업로드하기 전에 이 네 가지를 한 번에 설계하는 절차다.

## 핵심 원칙 (모든 규칙의 근거)

1. **약속과 이행이 같아야 한다.** 썸네일·제목이 약속한 것을 영상 초반에 바로 보여준다.
   유튜브의 A/B 테스트는 클릭률이 아니라 **시청 시간 점유율**로 승자를 정한다. 낚시성 썸네일은 클릭은 받아도 시청 시간에서 진다.
2. **썸네일과 제목은 역할을 나눈다.** 같은 말을 반복하지 않는다. 썸네일은 감정·장면, 제목은 정보·검색어.
3. **휴대폰 기준으로 판단한다.** 시청의 절반 이상이 모바일이다. 썸네일은 손톱만 한 크기에서 읽혀야 한다.
4. **채널의 일관성이 신뢰를 만든다.** 색·글꼴·배치를 시리즈마다 고정해, 썸네일만 보고도 우리 채널임을 알게 한다.
5. **영상 제작 전에 패키징을 먼저 정한다.** 제목과 썸네일이 정해지면 대본의 첫 30초도 자연히 정해진다.

## 작업 절차

사용자가 영상 주제(또는 대본·원고)를 주면 아래 순서로 진행한다. 정보가 부족하면 1단계의 질문만 짧게 묻고, 나머지는 합리적으로 가정한 뒤 가정을 밝힌다.

### 1단계. 기본 정보 확인
- 어느 채널인가: 한국어 학습 / 묵상
- 시청자 언어: 한국어 학습 채널이라면 제목·썸네일을 **시청자의 모국어**(대개 영어)로 쓸지 확인
- 이 영상을 보고 시청자가 **얻는 것 한 문장** (예: "카페에서 바로 쓸 주문 표현 5개", "불안한 밤에 붙들 시편 한 구절")
- 시리즈 여부와 회차

### 2단계. 제목 후보 5개 → 1개 추천
아래 "제목 규칙"을 지켜 서로 **각도가 다른** 후보 5개를 만든다 (호기심형, 결과형, 문제해결형, 숫자형, 대비형 등). 각 후보 옆에 어떤 각도인지 적고, 추천 1개와 이유를 쓴다.

### 3단계. 썸네일 설계안 3개
서로 **확실히 다른** 콘셉트 3개를 만든다 (유튜브 A/B 테스트는 최대 3개, 비슷하면 승자가 안 갈린다).
각 안은 "썸네일 설계 템플릿" 형식으로 쓴다. 디자인 툴(Canva 등) 접근이 있으면 실제로 만들어도 된다.

### 4단계. 첫 30초 훅 대본
"훅 규칙"에 맞춰 0~30초 대본을 쓴다. 썸네일·제목의 약속을 어떻게 바로 이행하는지 보여준다.

### 5단계. 설명란·챕터·해시태그
"설명란 템플릿"을 채운다.

### 6단계. 최종 점검
"업로드 전 체크리스트"를 하나씩 확인해 통과/수정 표시를 한다.

## 제목 규칙

- **핵심어는 앞 20자 안에.** 모바일·검색 결과에서 뒤가 잘린다. 전체는 40자(영어 60자) 안쪽을 권장, 최대 100자.
- **구체적인 것 하나.** "한국어 표현 배우기" ✗ → "한국인이 매일 쓰는 '대박' 말고 다른 말 7개" ✓
- **숫자는 아라비아 숫자로**, 기간·개수·단계처럼 의미 있는 숫자만.
- **썸네일 문구를 그대로 반복하지 않는다.** 썸네일이 "이 말 쓰면 실례?"라면 제목은 "한국 어른에게 절대 쓰면 안 되는 반말 표현 5가지".
- 느낌표·물음표는 최대 1개. 전부 대문자(영어), 이모지 남발 금지.
- 시리즈는 제목 끝에 표기: `| 하루 한 구절 #12`, `| Korean in 3 Minutes Ep.4`
- 검색으로 들어올 영상(How-to, 특정 성경 본문)은 **사람들이 실제로 검색할 말**을 제목에 넣는다 (예: "시편 23편 묵상", "Korean honorifics").

### 채널별 제목 공식

**한국어 학습** (시청자 언어로 작성)
- `[Korean phrase] — what it really means` → `"괜찮아요" Doesn't Always Mean "It's Okay"`
- `[숫자] [상황] phrases Koreans actually use` → `7 Phrases Koreans Actually Use at a Café`
- `Stop saying X, say Y instead` → `Stop Saying "안녕하세요" to Friends — Say This`
- `[레벨] + 결과` → `Beginner Korean: Order Food in 5 Minutes`

**묵상**
- `[본문] + 삶의 상황` → `불안한 밤에 읽는 시편 4편`
- `[질문형]` → `기도해도 응답이 없을 때, 하나님은 어디 계실까요?`
- `[짧은 위로의 문장] | [본문]` → `오늘도 충분합니다 | 마태복음 6:34`
- 피할 것: 과장·공포 조장("이것 모르면 큰일 납니다"), 자극적 낚시. 신앙 채널은 **신뢰가 곧 구독**이다.

## 썸네일 규칙

### 기술 사양
- 1280×720 px (16:9), JPG 또는 PNG, 2MB 이하. 720p 미만이면 A/B 테스트 시 전부 480p로 낮아진다.
- **오른쪽 아래 모서리 비우기**: 영상 길이 표시가 덮는다.
- 왼쪽 아래도 진행바·배지가 덮을 수 있으니 핵심 요소를 두지 않는다.

### 구성
- **초점은 하나.** 사람 얼굴 1개, 또는 사물 1개, 또는 큰 글자 1덩어리. 요소는 최대 3개.
- **글자는 3~4단어(한글 8자 안팎)까지.** 제목을 보충하는 감정·질문·반전만 쓴다.
- 글자 크기는 썸네일 높이의 1/5 이상, 굵은 고딕(예: Pretendard Black, Noto Sans KR Black, 검은고딕). 얇은 명조는 작게 보면 사라진다.
- **대비**: 밝은 배경엔 어두운 글자, 어두운 배경엔 밝은 글자. 글자에 외곽선이나 그림자를 넣어 배경과 분리한다.
- 얼굴을 쓸 땐 표정이 분명해야 한다 (놀람, 궁금함, 미소). 얼굴은 화면의 1/3 이상.
- 색은 2~3가지만. 채널 대표색 1개를 정해 모든 썸네일에 반복한다.
- **흑백 테스트**: 흑백으로 바꿔도 글자와 주제가 구분되면 대비가 충분하다.
- **축소 테스트**: 가로 160px 정도로 줄여도 무엇인지 알 수 있어야 한다.

### 채널별 썸네일 스타일

**한국어 학습**
- 큰 한글 표현 + 작은 시청자 언어 번역을 함께 (예: 크게 `괜찮아요?` / 작게 `"Are you okay?"`).
- ✗/✓, 빨강/초록 대비로 "틀린 말 vs 맞는 말"을 한눈에.
- 진행자 얼굴이 있다면 반응 표정을 넣는다. 레벨 배지(Beginner, TOPIK I 등)는 왼쪽 위 작은 고정 위치.

**묵상**
- 차분한 자연 사진(빛, 새벽, 길, 물) + 짧은 위로 문구 1줄. 여백을 충분히.
- 본문 표기(예: `시편 23편`)는 항상 같은 위치·같은 글꼴로 — 시리즈 정체성.
- 따뜻한 한 가지 강조색(골드, 앰버 등)을 고정. 과한 효과·빨간 화살표·충격 표정은 쓰지 않는다.
- 감성 명조체를 쓰고 싶다면 아주 굵은 것만, 큰 크기로. 작은 명조는 모바일에서 안 읽힌다.

## 훅 규칙 (첫 30초)

목표: 30초 시점에 **시청자의 60% 이상**이 남아 있는 것 (65% 이상이면 우수). 유튜브 스튜디오의 "인트로" 지표로 확인한다.

- **첫 문장에서 제목의 약속을 다시 말한다.** 인사·채널 소개·로고 애니메이션은 뒤로 미루거나 뺀다.
- 15초 안에 **"이 영상을 보면 무엇을 얻는지"** 를 분명히 한다.
- 결론의 일부를 먼저 보여주거나(예고), 질문을 던져 **열린 고리**를 만든 뒤 나중에 답한다.
- "안녕하세요 여러분, 오늘은~"으로 시작하지 않는다. 장면·질문·핵심 문장으로 바로 시작한다.

### 훅 템플릿

**한국어 학습**
```
[0-5초]  상황 장면 또는 문제 제기: "한국 친구가 '밥 먹었어?'라고 물으면, 진짜 밥 얘기가 아닐 때가 많아요."
[5-15초] 약속: "이 영상 끝나면 이런 인사말 5개를 자연스럽게 받아칠 수 있어요."
[15-30초] 첫 번째 표현을 바로 시작 (인사는 여기서 한 줄로 짧게)
```

**묵상**
```
[0-5초]  시청자의 마음을 짚는 한 문장: "잠이 오지 않는 밤이 있지요."
[5-15초] 오늘의 본문 한 구절 낭독 (화면에 구절 자막)
[15-30초] 오늘 묵상이 어디로 가는지 한 문장: "오늘은 다윗이 가장 불안했던 밤에 드린 기도를 함께 따라가 보겠습니다."
```

## 설명란 템플릿

첫 2줄(약 150자)만 '더보기' 전에 보인다. 여기에 핵심과 검색어를 넣는다.

```
[1줄] 이 영상이 주는 것 한 문장 (검색 키워드 포함)
[2줄] 누구를 위한 영상인지 / 시리즈 안내

⏱ 챕터
00:00 [훅 주제]
00:45 [첫 번째 부분]
02:10 [두 번째 부분]
...

📖 본문 / 📝 오늘의 표현 (묵상: 본문 전문과 역본 표기 / 한국어 학습: 표현·뜻·예문 정리)

🔗 관련 영상·재생목록 링크 1~3개
🔗 웹사이트 링크 (성경 웹페이지 등)

#해시태그1 #해시태그2 #해시태그3
```

- **챕터 규칙**: 첫 챕터는 반드시 `00:00`, 챕터는 3개 이상, 각 10초 이상. 3분 넘는 영상에는 챕터를 넣는다.
- 해시태그는 3개만 (앞의 3개가 제목 위에 표시된다). 채널명 태그 1개 + 주제 2개.
- 성경 구절을 인용하면 **역본을 표기**한다 (예: 개역개정, 새번역). 저작권이 있는 역본은 인용 범위 안에서만 쓴다.

## 업로드 전 체크리스트

- [ ] 제목의 핵심어가 앞 20자 안에 있다
- [ ] 썸네일 글자와 제목이 같은 말을 반복하지 않는다
- [ ] 썸네일 글자는 4단어 이하, 160px 축소에서도 읽힌다
- [ ] 썸네일 오른쪽 아래가 비어 있다
- [ ] 흑백으로 봐도 주제와 글자가 구분된다
- [ ] 채널 대표색·글꼴·배치를 지켰다
- [ ] 영상 첫 15초 안에 썸네일·제목의 약속을 이행하거나 명확히 예고한다
- [ ] 인사·로고·채널 소개가 첫 10초를 차지하지 않는다
- [ ] 설명란 첫 2줄에 핵심과 검색어가 있다
- [ ] 챕터가 00:00으로 시작하고 3개 이상이다
- [ ] 성경 인용에 역본을 표기했다
- [ ] 과장·공포·허위 약속이 없다

## 업로드 후 개선 루프

1. 48시간 뒤 유튜브 스튜디오에서 **노출 클릭률(CTR)** 과 **30초 시점 시청 유지율**을 확인한다.
2. 비교 기준은 다른 채널이 아니라 **내 채널의 비슷한 길이 영상 평균**이다.
3. CTR이 평균보다 낮으면 → 썸네일·제목 문제. "테스트 및 비교"(PC 유튜브 스튜디오)로 3단계의 다른 안을 걸어 본다. 테스트 중 제목·썸네일을 바꾸면 테스트가 멈춘다.
4. CTR은 괜찮은데 30초 유지율이 낮으면 → 약속과 첫 장면이 어긋난 것. 다음 영상의 훅을 고친다.
5. 결과(어떤 안이 이겼는지, 수치)를 한 줄로 기록해 두고, 이긴 패턴을 다음 영상에 반복한다.

사용자에게는 다음 순서로 한 번에 전달한다.

```
## 제목
추천: ...
후보: 1) ... (각도) 2) ... 3) ... 4) ... 5) ...

## 썸네일 3안

- 배경:
- 주 피사체/위치:
- 글자 (크게):         글자 (작게, 선택):
- 색: 배경 / 글자 / 강조
- 글꼴:
- 왜 클릭하나:
### B안 ...
### C안 ...

## 첫 30초 대본
...

## 설명란
...

## 체크리스트 결과
...
```

근거 자료는 [references/sources.md](references/sources.md)에 정리되어 있다.
